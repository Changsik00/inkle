# 실험 05: 다른 시선, 실제 수집으로 보기

> spec-01-10, 2026-11-20. spec-01-08 의 find.v2 수집(두 책)을 새 규칙(작가 본인은 따로, 흔함 없음)으로 시선 화면에 띄운 기록.
> LLM 호출 없음: 기존 수집을 그대로 읽었다. 흔함 정도는 수집 때 매긴 값(작가 본인 포함으로 매김)을 쓴다.

## 결과

| 책 | 다른 사람 (평론가·기자 / 독자 / 그 밖) | 작가 본인 | AI 가 만든 해석 | 흔함 (많이 / 일부 / 드문) | 인용 (외국어) |
|---|---|---:|---:|---|---|
| 『채식주의자』 | 9 (4 / 5 / 0) | 3 | 0 | 4 / 3 / 2 | 22 (8) |
| 『노인과 바다』 | 17 (7 / 9 / 1) | 1 | 0 | 5 / 5 / 7 | 30 (12) |

- 두 책 모두 다른 사람의 시선이 기준(3개)을 넘어 AI 가 만든 해석은 만들어지지 않았다. AI 가 만든 해석은 대역 LLM 테스트로만 확인했다 (`application/collection.test.ts`).
- 다른 사람의 시선은 많이 → 일부 → 드문 순으로 나왔다.
- 작가 본인의 시선 넷(『채식주의자』 셋, 『노인과 바다』 하나)에는 수집 때 "많이 나온 읽기" 둘, "일부의 읽기" 둘이 저장되어 있었다. 화면과 API 는 이제 내주지 않는다. 작가 본인 셋이 빠진 채 다시 매기면 『채식주의자』 의 값은 달라질 수 있다 (다시 모을 때 반영).

## 화면

- `docs/design/screens/perspectives.png`: 『채식주의자』 (공개해도 되는 가상 해석의 모임. 이 화면에는 내 해석이 나오지 않는다).

## 알게 된 것

1. **"누가"와 "어떤 사람"이 겹친다.** 읽기 단계가 만든 이름에 "독자 블로그(브런치 글쓴이)"처럼 종류가 이미 들어 있어 "· 독자" 가 되풀이된다. 해가 없어 그대로 둔다. 읽기 지시문을 고칠 때 이름만 받게 한다.
2. **화면이 길다.** 『채식주의자』 는 시선 12개, 인용 22개라 한 화면이 길다. 비교(spec-01-11)에서 내 해석과 맞닿는 시선을 앞에 두면, 이 화면은 접어 두는 쪽으로 바꿀 수 있다 (배경 화면처럼).
3. **작가 본인의 말이 셋이면 서로 비슷하다.** 『채식주의자』 의 셋은 같은 인터뷰(Lit Hub)에서 나와 "폭력과 순수, 거부"를 조금씩 다르게 말한다. 출처별로 묶는 일은 필요해지면 한다.
