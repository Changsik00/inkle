> spec-01-09, 2026-11-20. 수동 실험의 해석 두 편을 실제 모임에 저장하고, spec-01-08 이 모은 배경과 연결을 만든 기록.
> 실행: API 로 모임을 열고 내 해석을 저장 → `INKLE_LLM_MODEL=claude-sonnet-5-5 pnpm worker`.
> 『노인과 바다』 의 해석 원문은 `01-manual-flow/raw/` 에만 있다 (공개 저장소에 올리지 않음). 여기에는 그 구절을 옮기지 않고 `book-1.md` 의 요약 수준으로만 적는다. 『채식주의자』 는 가상 해석이라 구절을 그대로 적는다.

- v2 는 같은 답을 판 2 로 다시 저장해 만들었다. 판 1 의 연결은 그대로 남았다 (ADR-005).

## v1 → v2 로 고친 것

| 문제 (v1) | 고친 것 (`prompts/connect.v2.ts`) | v2 결과 |
|---|---|---|
| 독자의 답 대신 **질문 문장**("작가는 왜 이렇게 썼다고 생각하나요?")을 옮긴 연결이 하나 있었다. 대조가 걸러 화면에는 나가지 않았다 | 옮길 곳을 "답:" 뒤의 글로 못박고, 질문 문장은 옮기지 않으며 틀린 맞춤법도 고치지 않는다고 적었다 | 9/9 통과 |
| "맞닿는 곳"이 배경 설명을 거의 그대로 되풀이했다 | 독자의 구절과 배경 사이의 관계(뒷받침 / 다른 각도 / 그 생각이 나온 자리)를 말하게 했다 | 모두 관계를 말한다 (아래 예) |

v2 의 "맞닿는 곳" 예:

- "2부의 형부 이야기는 왜 들어갔는지 모르겠다" → "2부가 왜 들어갔는지 묻는 이 구절에 대해, 연작이라는 구성 쪽에서 본 다른 각도를 보여 준다."
- "작가는 사회를 고발하려고 썼다고 생각한다" → "사회 고발이라는 읽기와는 다른 각도에서 작가가 밝힌 의도를 전한다." (작가: 폭력과 아름다움이 뒤섞인 세계에서 순수가 가능한가라는 보편적 질문)
- (『노인과 바다』, 질문 3: 고기를 잃어 돈을 얻지 못한 아쉬움) → 작품 밖에서 받은 퓰리처상·노벨상을 "작품 안의 명예와는 다른 자리에서 얻은 인정"으로 놓는다.

독자를 평가하는 문장(성향, 수준, 맞다·틀리다)은 여덟 개 연결(v1 통과분)과 아홉 개 연결(v2) 어디에도 없었다.

## 수동 실험과 비교

| 책 | 수동 실험 | 이번 |
|---|---|---|
| 『채식주의자』 | 배경 넷을 해석 1번·4번에 이음. "제목의 아이러니"(노벨상 기자회견)도 있었다 | 다섯. 채식↔육식은 폭력이라는 작가 설명, 결말↔식물 이미지에서 출발, 사회 고발↔"보편적 질문"은 수동 실험과 같은 쟁점이다. **2부 형부 이야기↔연작 구성**은 수동 실험이 찾지 못한 연결이다. 제목의 아이러니는 이번 수집에 그 출처가 없어 빠졌다 |
| 『노인과 바다』 | 사실 다섯, 그중 셋은 "확인하지 못함" | 넷, 모두 출처 문장으로 확인된 배경. "상징은 없다"는 작가의 말이 "위로는 받았지만 현실은 현실"이라는 읽기(질문 4) 옆에 "다른 각도"로 놓였다 |

『채식주의자』 해석의 사실 오류("영혜가 직접 들려주는 1인칭 소설")는 이번에 짚지 않는다. 배경의 일이 아니라 비교("책과 어긋나는 곳", spec-01-10)의 일이다.

## 알게 된 것

1. **내 글에도 대조가 통한다.** 출처 인용과 같은 규칙으로 질문 문장을 옮긴 연결을 걸렀다. 지시를 고친 뒤에는 걸릴 것이 없었다.
2. **출처의 종류 분류가 틀린 것이 하나 보였다.** 주간경향 기사가 2010년 인터뷰를 옮긴 문장이 "직접 한 말"로 표시됐다. 수동 실험은 같은 문장을 "직접 인용이 아님"으로 봤다. 종류는 읽기 단계(LLM)의 판단이고 대조로 확인되지 않는다 (ADR-004 §Consequences "부정").
3. **E2E 가 남긴 수집이 작업 프로세스를 기다리고 있었다.** 시험용 책 21권의 수집이 대기 중이었다. 그대로 작업 프로세스를 띄우면 가짜 책을 실제로 수집하느라 구독 사용량을 쓴다. 이번에는 손으로 실패 처리했다.
