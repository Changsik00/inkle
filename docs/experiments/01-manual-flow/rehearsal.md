## 가상의 해석

1. 폭력적인 가부장 사회에서 한 여성이 채식이라는 방식으로 저항하는 이야기다. 영혜가 직접 자기 이야기를 들려주는 1인칭 소설이라 더 답답하게 읽혔다. *(일부러 넣은 사실 오류)*
2. 아버지가 억지로 고기를 입에 넣는 장면이 가장 남았다.
3. 2부의 형부 이야기는 왜 들어갔는지 모르겠다. 예술을 핑계로 한 착취로만 보였다.
4. 영혜가 나무가 되려는 결말은 죽음을 택한 것이고 패배다. 작가는 사회를 고발하려고 썼다고 생각한다.

### 비교

- **책과 어긋나는 곳**: "영혜가 직접 들려주는 1인칭 소설"은 사실과 다르다 (1부는 남편, 2부는 형부, 3부는 언니의 자리에서 서술되고 영혜의 목소리는 꿈 독백으로만 나온다). 다만 이 지적의 근거는 검색으로 얻지 못했고 모델의 기억이다. 출처를 붙일 수 없었다.
- **다르게 읽은 곳**: "가부장제에 대한 저항"은 다수 연구와 겹친다. "사회 고발"은 작가의 "질문으로 읽어 달라"와 갈린다. "결말은 패배"는 참여사회 서평의 "새로운 주체성"과 갈린다. 폭력 일반과 결백의 문제, 제목의 아이러니는 다루지 않았다.

## 알게 된 것

1. **검색 요약은 출처가 아니다.** 주소는 모두 실제로 열렸지만, 요약이 글에 없는 주장을 덧붙이거나 과장했다. 페이지를 직접 열어 문장을 확인하는 단계가 반드시 있어야 한다.
2. **"작가가 한 말"에도 단계가 있다.** 직접 인용, 기자의 정리, 다른 글을 거친 재인용이 섞여 나온다. 구분해서 표시해야 한다.
3. **배경을 내 해석에 연결하는 것은 효과가 있다.** "질문으로 읽어 달라"와 제목의 아이러니는 일반적인 작품 소개에서는 묻히지만, "사회 고발"과 "채식으로 저항"이라는 해석 옆에 놓이면 바로 쟁점이 된다.
4. **찾아지는 시선이 한쪽으로 쏠린다.** 한국어 검색은 에코페미니즘 연구가 대부분이었고, 가상의 독자도 같은 방향이었다. 서로 다른 시선을 얻으려면 "반대로 읽은 글"을 따로 찾아야 한다.
5. **일반 독자의 반응은 검색으로 잘 나오지 않는다.** 평론과 기사 위주로 나온다. 독서 모임에서 듣는 "보통 독자의 감상"은 다른 경로가 필요하다.
6. **오독의 근거는 수용 자료 검색으로는 나오지 않는다.** 서술 시점 같은 사실은 평론을 찾는 검색에 걸리지 않았다. 줄거리와 구성을 확인하는 검색을 따로 하거나, 모델의 기억에 의존한다는 것을 표시해야 한다.
7. **확인 비용이 크다.** 출처 7개를 여는 데 검색보다 훨씬 많은 처리량이 들었다 (약 10만 토큰). 모임 한 번의 비용과 대기 시간에 영향을 준다.

## 프롬프트에 반영한 것

- 검색 결과의 요약만 보고 쓰지 말고 페이지를 열어 확인하도록 규칙을 강화. 열어 보지 못한 것은 "요약만 확인"으로 표시
- 작가의 말을 직접 인용 / 기자의 정리 / 재인용으로 구분
- 다른 시선 단계에 "내 해석과 반대로 읽은 글"과 "일반 독자의 리뷰"를 따로 찾도록 추가
- 비교 단계에서 줄거리와 구성을 확인하는 검색을 하고, 기억에만 근거한 지적은 그렇게 표시
