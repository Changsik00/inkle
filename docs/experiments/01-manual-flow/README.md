# 실험 01: 흐름을 손으로 돌려 보기

> spec-01-01. 코드를 만들기 전에 inkle 의 흐름이 일반 AI 채팅보다 나은지 확인한다.

## 확인하려는 것

1. inkle 방식이 "내 해석을 붙여 넣고 물어보는" 일반 채팅보다 나은가
2. 모임을 열고 나면 내 생각이 달라지는 지점이 생기는가
3. 실제 평론과 독자 반응이 검색으로 충분히 찾아지고, 출처가 그 내용을 실제로 담고 있는가
4. 책 본문 없이 "책과 어긋나는 곳"을 믿을 만하게 짚을 수 있는가
5. 배경을 내 해석을 쓰기 전에 보는 것과 쓴 뒤에 보는 것 중 어느 쪽이 나은가
6. 소설과 비문학에서 흐름과 표현이 어떻게 달라야 하는가

## 준비

- **책 2권**: 최근에 읽어 기억이 생생한 소설 1권과 비문학 1권. 가능하면 한 권은 한국어 책, 한 권은 덜 알려진 책.
- **도구**: 웹 검색이 켜진 Claude 채팅. 두 방식 모두 같은 모델을 쓴다.
- **깨끗한 대화**: 방식마다 새 대화를 연다. 메모리나 프로젝트 지침이 켜져 있으면 끄거나 임시 대화를 쓴다. 이전 대화가 섞이면 비교가 흐려진다.

## 책별 배정

| | 책 1 | 책 2 |
|---|---|---|
| 배경을 보는 시점 | 내 해석을 쓴 뒤 (순서 A) | 내 해석을 쓰기 전 (순서 B) |
| 프롬프트 | 장르에 맞는 것 | 장르에 맞는 것 |

어느 책을 1번으로 할지는 자유다. 소설과 비문학 중 무엇이 A 가 되는지는 결과 해석에 큰 영향이 없다.

## 책 한 권의 절차 (약 1시간)

1. **내 해석 쓰기 (10~15분)** — 채팅을 열기 전에, `prompts.md` §1 의 질문에 대한 답을 메모장에 먼저 쓴다. 검색하거나 다른 글을 찾아보지 않는다. 순서 B 인 책은 3번의 배경 단계를 먼저 하고 돌아온다.
2. **inkle 방식 시작** — 새 대화에 `prompts.md` §2 의 시작 프롬프트를 붙여 넣는다.
3. **단계 진행** — AI 의 안내에 따라 책 정보, 내 해석, 배경, 다른 시선, 비교, 토론, 노트 순으로 진행한다. 토론은 5~10번 주고받으면 충분하다.
4. **달라진 점 쓰기** — 노트 단계에서 "달라진 점"을 직접 쓴다. 없으면 "달라지지 않았다"고 쓴다.
5. **출처 열어 보기 (10~15분)** — 배경과 다른 시선에 붙은 출처를 모두 열어 내용을 담고 있는지 확인한다.
6. **일반 채팅 (10분)** — 다른 새 대화에 `prompts.md` §3 을 붙여 넣는다. 평소 하듯 몇 번 더 물어봐도 된다. 여기서 받은 출처도 열어 본다.
7. **기록** — `record-template.md` 를 복사해 채운다. 대화 원문은 `raw/` 폴더에 저장한다 (커밋되지 않는다).

inkle 방식을 먼저 하고 일반 채팅을 나중에 한다. 순서를 바꾸면 "먼저 쓰고 그다음 본다"가 깨진다. 대신 일반 채팅은 이미 본 내용을 다시 듣는 쪽이라 불리하다. 기록할 때 "처음 봤다면 어땠을까"를 감안해 적는다.

## 판단 기준 (실험 전에 고정)

| 판단 | 조건 |
|---|---|
| 계속 | 2권 모두에서 달라진 생각이 1개 이상 있고, 1권 이상에서 일반 채팅보다 낫고, 내용을 담고 있지 않은 출처가 전체의 10% 이하 |
| 중단 검토 | 2권 모두에서 일반 채팅보다 낫지 않다 |
| 수정 후 재실험 | 그 사이의 모든 경우 |

판단은 사용자가 내리고, 근거는 `findings.md` 에 적는다.

## 파일

| 파일 | 내용 | 커밋 |
|---|---|:---:|
| `prompts.md` | 내 해석 질문, inkle 방식 시작 프롬프트, 일반 채팅 프롬프트 | O |
| `record-template.md` | 책별 기록 양식 | O |
| `book-1.md`, `book-2.md` | 책별 기록 (수치와 요약) | O |
| `rehearsal.md` | 가상의 해석으로 돌려 본 리허설 기록 | O |
| `findings.md` | 두 권 비교, 판단, 열린 질문의 답 | O |
| `raw/` | 내 해석 원문과 대화 원문 | X (gitignore) |

저장소가 공개 상태이므로 원문은 커밋하지 않는다. `book-*.md` 에도 내 해석과 외부 글을 길게 옮기지 않는다.
