## 🔍 발견 사항

- **zod 4 의 `z.toJSONSchema` 가 붙이는 `$schema` 를 CLI 가 거부한다.** 넘기기 전에 뺀다.
- **내부 주소로 넘기는 리디렉션 차단은 직접 시험하지 못했다.** 시험 서버가 127.0.0.1 이라 막히기 때문이다. 넘겨주기마다 같은 검사(`check`)를 거치는 것은 "http(s) 가 아닌 곳으로 넘기기" 시험으로 확인했다.
- **작업 프로세스는 진행 중인 작업이 있으면 SIGTERM 으로 멈추지 않는다.** 끝내기를 기다리는 구조다. 강제로 멈추면 작업과 수집이 "진행 중"으로 남는다. 수집은 2시간 규칙으로 풀리지만 `jobs` 의 작업은 손으로 실패 처리했다 (작업 11). 작업 대기열의 멈춘 작업 처리는 아직 없다.
- **작가 본인의 말에도 흔함 정도가 붙는다** (`rare`, `majority`). 뜻이 없다. 시선 화면(spec-01-10)에서 정한다.
- **find.v2 는 배경 항목을 줄였다** (18 → 10, 25 → 9). 배경 화면(spec-01-09)에서 부족하면 배경과 시선의 찾기를 나눈다.
- **열렸는데 항목이 없는 출처가 있다** (번역 오류 비판 기사, 줄거리 위주 독자 글).
- **E2E 는 개발 DB 에 시험용 책의 수집을 대기로 남긴다.** 작업 프로세스를 띄우면 실제로 수집된다 (구독 사용량). 시험용 책 이름은 `E2E 시험용 책 …`.
- **스코프 훅이 spec.md 의 중괄호 경로(`{llm/claude-code-cli.ts, …}`)를 읽지 못해** CLI 파일을 범위 밖이라고 경고했다. 오탐.
